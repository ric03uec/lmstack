# lmstack

Development-focused local model stack for DGX and other GPU-capable machines,
including local AMD/ROCm and Apple Silicon systems.

## Objectives

- provide a fully functioning local LLM stack for development workflows
- serve models through a stable OpenAI-compatible interface
- support multiple local inference backends across NVIDIA, AMD/ROCm, and macOS
  GPU environments
- keep setup, operations, and model switching simple
- make the stack easy to reproduce, verify, and extend
